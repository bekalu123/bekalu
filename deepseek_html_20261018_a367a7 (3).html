እንኳን ወደ ኮልፌ ኢንዱስትሪያል ኮሌጅ የጨረታ ማወዳደሪያና ሰፕላየር መምረጫ ሲስተም በሰላም መጡ!

የሲስተሙ አጠቃቀም መመሪያ / System Usage Guide:
1. አቅራቢ መምረጫ → የዋጋ ማስገቢያ → የገበያ ጥናት መረጃዎችን ያስገቡ።
2. አሸናፊ መምረጫ ታብ በመጠቀም አሸናፊዎችን በራስ-ሰር ይለዩ።
3. ማጠቃለያ ሪፖርት እና አሸናፊ ደብዳቤ በመጠቀም ሪፖርቶችን ይመልከቱ እና ደብዳቤዎችን ያትሙ።
መመሪያ / Instruction: እያንዳንዱን ሎት በመምረጥ በቴክኒክ ያለፉ ተወዳዳሪ ሰፕላየሮችን ኮድ ብቻ ይምረጡ።
ተ.ቁ የእቃው አይነት መግለጫ (Specification) መለኪያ ብዛት ተወዳዳሪ ሰፕላየሮች (ኮድ ብቻ / Codes Only)
መመሪያ / Instruction: የተመረጡ ሰፕላየሮች የገባላቸውን የዋጋ ዝርዝር እዚህ ላይ አስገብተው ዋጋዎችን አስቀምጥ ወይም አፕዴት አድርግ የሚለውን ይጫኑ።

ታብ 11 - የገበያ ጥናት ዋጋዎች አስተዳደር (Market Price Management)

መመሪያ / Instruction: ሎት ይምረጡ፤ የዛ ሎት እቃዎች በሙሉ በራስ-ሰር ይወጣሉ። ዋጋዎቹን ኤዲት አድርገው የገበያ ጥናት አስቀምጥ ይጫኑ።
ተ.ቁ የእቃው አይነት መግለጫ መለኪያ ብዛት የገበያ ጥናት ዋጋ (ብር)
የአሸናፊ መምረጫ መመሪያ: ሎት ይምረጡና አሸናፊ ለይ የሚለውን በተን ሲጫኑ የጨረታው አሸናፊዎች በሰንጠረዥ ይወጣሉ።
ተ.ቁየእቃው አይነትመግለጫመለኪያብዛት የገበያ ጥናት ዋጋአነስተኛ የነጠላ VAT ያካተተ ዋጋ ጠቅላላ አነስተኛ ዋጋአሸናፊ ድርጅት ስምየድርጅት ኮድሁኔታ
ማጠቃለያ ሪፖርት መመሪያ: ሎት ይምረጡ እና ማጠቃለያ ሪፖርት አሳይ የሚለውን በመጫን ሙሉውን የውድድር ውጤት ይመልከቱ።
መመሪያ / Instruction: ሎት እና አሸናፊ ነጋዴ ይምረጡ (አሸናፊዎች በዋንጫ 🏆 ምልክት ይታወቃሉ)። በስም መፈለግ ይችላሉ።
